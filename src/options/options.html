Lili

Traduire, reformuler, résumer — sans quitter la page.

Connexions

Ajoute un ou plusieurs services. Lili appelle directement leur API : rien ne transite par un serveur intermédiaire. Chaque tâche pourra ensuite utiliser une connexion et un modèle différents.

Modèles par tâche

Choisis la connexion et le modèle de chaque tâche. Laisse la connexion sur « Par défaut » pour réutiliser la connexion par défaut ; laisse le modèle vide pour utiliser le modèle par défaut de la connexion.

Les modèles de traduction dédiés (par exemple Olala-v1.0-translate) reçoivent automatiquement les langues source et cible, sans prompt système. Sur « Reformuler + traduire », un tel modèle traduit sans reformuler.

Limites

Au-delà de ces limites, le texte est tronqué (résumé de page) ou refusé (sélection).
