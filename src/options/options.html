Lili

Traduire, reformuler, résumer — sans quitter la page.

v0.1.0

Fournisseur

Lili appelle directement l’API depuis le navigateur. Rien ne transite par un serveur intermédiaire : ton texte part uniquement vers le fournisseur choisi.

L’endpoint /chat/completions est ajouté automatiquement.

Pour autoriser l’extension, lance Ollama avec OLLAMA_ORIGINS="*" (ou l’origine de l’extension).

Le modèle doit être téléchargé : ollama pull llama3.1:8b.

À l’enregistrement, le navigateur demandera l’autorisation d’accéder à cet hôte. C’est nécessaire pour contourner les restrictions CORS.
