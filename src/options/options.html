Lili

Translate, rephrase, summarize — without leaving the page.

Connections

Add one or more services. Lili calls their API directly: nothing goes through an intermediate server. Each task can then use a different connection and model.

Models per task

Pick the connection and model for each task. Keep the connection on “Default” to reuse the default connection; leave the model empty to use the connection’s default model.

Dedicated translation models (for example Olala-v1.0-translate) automatically receive the source and target languages, with no system prompt. On “Rephrase + translate”, such a model translates without rephrasing.
